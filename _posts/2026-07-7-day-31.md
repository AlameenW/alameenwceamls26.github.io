what_i_learned: |
  From dummy model to real model. Today the placeholder ONNX model in our FastAPI damage-classification app got replaced with the team's actual trained baseline, and what looked like a file swap turned into detective work.    Turns out a .pth checkpoint stores only learned weights, no architecture, so the serving side has to rebuild the exact model skeleton in code before loading. Reading the actual training notebook revealed the real            architecture, the checkpoint's structure, and the training resolution — three things the serving code had to match exactly. The rule underneath was to serve the model exactly what training served it. Mismatches don't        throw errors, they just quietly degrade accuracy. After exporting to ONNX, one habit paid off again: verify the contract. Open the exported file the same way the server will and print its actual inputs and outputs. Ours     matched  and the app now serves real predictions from our real baseline. Recurring lesson this summer: written guides are snapshots of someone else's environment. When the document and the evidence disagree, trust the       evidence.
